# Aventura matemática

Proyecto educativo independiente para regulación de matemáticas de Teocallintzin.

## Juego 01: El templo de los números
Diez misiones con tres rutas: Con apoyo, Práctica y Reto. Valor posicional, cero, agrupaciones, comparación y problemas. Cada misión se trabaja en cuaderno antes de responder.

Abrir `index.html` en un navegador o usar GitHub Pages. No requiere dependencias, cuentas ni conexión para la copia descargada. El progreso se guarda en el navegador; no se envía a Classroom. Para un alumno diferente usar Nueva partida.

Este repositorio no usa datos, código ni configuración del proyecto Multimarcas.
